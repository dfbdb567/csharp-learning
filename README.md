# csharp-learning

Учебные проекты по C# (.NET 10).

## todo

Консольный TODO-менеджер.

Возможности:
- добавление задач — обычных и срочных;
- просмотр списка;
- удаление по номеру;
- отметка выполнения.

Устройство:
- `ToDo` — одна задача (название, статус, `Describe()`);
- `UrgentTodoItem : ToDo` — срочная задача, переопределяет `Describe()`;
- `ITodoList` — контракт хранилища задач;
- `TodoList : ITodoList` — реализация, хранит задачи в памяти.

### Запуск

```powershell
dotnet run --project todo
```
